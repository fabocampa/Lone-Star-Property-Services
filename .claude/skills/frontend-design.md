# Frontend Design Guide

## Core Philosophy
Treat design as a deliberate, opinionated practice. Ground every choice in the subject — derive decisions from the actual domain and context of what's being built, not from generic defaults.

## Key Principles

**Typography as personality:** Type pairing should be specific to each project, establishing a clear type scale with intentional weights, widths, and spacing rather than reusing familiar combinations.

**Structure encodes meaning:** Numbered sequences, dividers, and labels should reflect genuine information hierarchy, not decorative convention. Avoid using "01 / 02 / 03" unless the content actually requires sequential ordering.

**One signature element:** Concentrate boldness in a single memorable feature while keeping surrounding details quiet and disciplined — don't scatter effects throughout.

**Motion with purpose:** Animation should serve the subject and direction — either orchestrated moments or restraint — avoiding the scattered effects that signal AI-generated work.

## Process
Two passes:
1. Develop a compact design system (color palette, typefaces, layout concept, signature element)
2. Critique it against the brief — ensure choices feel specific rather than default before building

## Writing as Design Material
Copy requires the same intentionality as visual elements. Content should be plain, active, and consistent throughout the experience, serving navigation and clarity rather than decoration.
